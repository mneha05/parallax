# Statistical assumptions

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

Before a Welch test, check independence and report sample sizes and variance differences. Before a rank-sum test, distinguish distributional shifts from median-only claims. Do not interpret p-values as probability that a hypothesis is true.

## Reviewer record
- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
