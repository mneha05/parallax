# Change-point review

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

Compare the detected breakpoint to raw return counts and deployment dates. Save the bootstrap seed and CI method. Consider seasonality, batch effects, and data collection changes before treating a breakpoint as product deterioration.

## Reviewer record
- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
