# Outlier lot review

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

Review lot sizes and missing features before calculating MAD-standardized distances. Small lots may appear extreme due to sampling noise. Distinguish rank ordering from calibrated fault probabilities and retain original measurements.

## Reviewer record
- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
