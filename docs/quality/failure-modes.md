# Failure modes

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

Inspect missing input, malformed specialist output, exhausted tool budget, numerical non-convergence, and partial stream interruption. Report failure clearly rather than silently replacing unavailable evidence with invented numbers.

## Reviewer record
- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
