# Regression matrix

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

Exercise each specialist skill with ordinary, degenerate, and boundary data. Include empty groups, equal observations, extreme skew, all-censored samples, and tied ranks. Add deterministic reference fixtures when comparing numerical implementations.

- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
