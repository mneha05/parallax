# Agent trace review

Guidance for reviewing PARALLAX multi-agent reliability investigations on its synthetic demonstration dataset.

For each director delegation record specialist name, user question, skill calls, parameters, returned numerical evidence, and synthesis references. A final brief must not introduce new quantitative claims unsupported by the trace.

## Reviewer record
- Dataset version and commit SHA
- Selected tool and its input arguments
- Evidence, caveats, and unresolved questions
- Reviewer decision and follow-up
